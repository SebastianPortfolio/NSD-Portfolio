# Model Selection Project

This project demonstrates key strategies for selecting the best predictive model from a set of candidates. It explores variable selection, regularization, and validation techniques to enhance model performance and interpretability.

---

## Objective

To apply and compare model selection techniques such as best subset selection, stepwise selection, and regularization (Ridge, Lasso), using training/test splits and cross-validation to guide decision-making.

---

## Methods Used

- Best subset selection
- Forward and backward stepwise selection
- Regularization techniques: Ridge regression and Lasso
- Model evaluation using cross-validation, Cp, BIC, and Adjusted R²

---

## Project Files

- `Code Walkthrough Project Overview Model Selection and Regularization Techniques.Rmd` – Fully annotated R code implementing all selection techniques.
- `Project Overview Model Selection and Regularization Techniques.pdf` – Written summary explaining methods and comparative results.
- `R_Model_Selection.pdf` – Visual summary with model comparison charts.
- `README.md` – This file.

---

## Learning Outcome

Through this project, you'll:

- Learn how to reduce model complexity without sacrificing predictive power
- Understand how different selection criteria (Cp, BIC, etc.) influence model choice
- Apply penalized regression techniques (Ridge, Lasso) in practical scenarios
