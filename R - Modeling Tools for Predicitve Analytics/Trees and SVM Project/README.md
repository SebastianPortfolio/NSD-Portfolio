# Trees and SVM Project

This project compares decision trees, ensemble methods (bagging and random forests), and support vector machines (SVMs) for regression and classification tasks using the `Carseats.csv` and `OJ.csv` datasets.

---

## Objective

To evaluate the performance, interpretability, and generalization capabilities of tree-based models and SVMs in predictive modeling.

---

## Methods Used

- Regression trees and pruning
- Bagging and random forests
- Support vector classification with linear, radial, and polynomial kernels
- Model comparison using test set performance and cross-validation

---

## Project Files

- `Carseats.csv` – Dataset for regression tree and ensemble methods.
- `OJ.csv` – Dataset for SVM classification.
- `Code Walkthrough Decision Trees, Bagging, Random Forest, and SVM Classification.Rmd` – Complete R code with annotations and plots.
- `Project Overview Decision Trees, Bagging, Random Forest, and SVM Classification.pdf` – Summary of findings and insights across all models.
- `R_Trees_and_SVM.pdf` – Slide-style visual summary.
- `README.md` – This file.

---

## Learning Outcome

This project helps you:

- Understand how different tree-based methods compare in terms of bias-variance tradeoff
- Learn how kernel choice affects SVM performance
- Use variable importance plots and error metrics to guide model evaluation
