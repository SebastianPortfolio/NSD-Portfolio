# Bias-Variance Tradeoff Project

This project demonstrates the core concept of the bias-variance tradeoff in predictive modeling. Using polynomial regression on the `Auto.data` dataset, it visualizes how increasing model complexity affects training and test error.

---

## Objective

To explore how underfitting and overfitting manifest as model flexibility changes, and how this impacts prediction accuracy.

---

## Methods Used

- Polynomial regression (varying degrees)
- Train/test data splitting
- Error analysis using visual plots
- Model evaluation using Mean Squared Error (MSE)

---

## Project Files

- `Auto.data` – Raw dataset used for modeling.
- `BiasVariance_Tradeoff.pdf` – A concise visual summary of key insights.
- `Code_Walkthrough_Bias-Variance Trade-off.Rmd` – Full annotated R Markdown code used in the analysis.
- `Project Overview Bias-Variance Trade-off.pdf` – A written explanation of the project findings, including theoretical background and practical interpretation.
- `README.md` – This file.

---

## Learning Outcome

This project helps reinforce:
- The impact of model complexity on generalization.
- How to balance bias and variance through visual and statistical diagnostics.
- The importance of validation data in model evaluation.
