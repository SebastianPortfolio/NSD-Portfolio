# Linear Regression Project

This project focuses on applying linear regression techniques to real-world data, emphasizing model diagnostics, interpretability, and assumptions checking using the `Auto.data` dataset.

---

## Objective

To fit linear models, evaluate their accuracy, and assess diagnostic measures that indicate model quality and potential issues such as multicollinearity and non-linearity.

---

## Methods Used

- Simple and multiple linear regression
- Residual analysis
- R² and Adjusted R² evaluation
- Diagnostic plots (residuals vs. fitted, Q-Q plot, leverage)
- Multicollinearity checks (Variance Inflation Factor)

---

## Project Files

- `Auto.data` – Dataset used for regression modeling.
- `Code Walkthrough Linear Regression and Model Diagnostics.Rmd` – Annotated R code with diagnostic plots and model evaluation.
- `Project Overview Linear Regression and Model Diagnostics.pdf` – Written explanation of methods, assumptions, and insights.
- `R_Linear_Regression.pdf` – Visual summary of regression models and diagnostics.
- `README.md` – This file.

---

## Learning Outcome

By completing this project, you'll understand:

- How to build and interpret linear regression models in R
- When model assumptions are violated and how to detect them
- The relationship between predictor variables and multicollinearity
