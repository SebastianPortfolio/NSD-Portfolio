# Classification Project

This project applies and compares multiple classification methods for binary prediction tasks using the `Auto.data` dataset. It evaluates each model's strengths, assumptions, and prediction performance.

---

## Objective

To understand and contrast various supervised classification techniques by applying them to a real dataset and interpreting results across different metrics.

---

## Methods Used

- Logistic Regression
- Linear Discriminant Analysis (LDA)
- Quadratic Discriminant Analysis (QDA)
- K-Nearest Neighbors (KNN)
- Performance evaluation using confusion matrices and error rates

---

## Project Files

- `Auto.data` – Dataset used for modeling.
- `Code Walkthrough Classification Methods in Statistical Learning.Rmd` – Complete annotated R Markdown file with implementation and output.
- `Project Overview Classification Methods in Statistical Learning.pdf` – Summary of theoretical background, method comparison, and conclusions.
- `R_Classification.pdf` – Slide-style report visualizing model results and performance comparisons.
- `README.md` – This file.

---

## Learning Outcome

Through this project, you will:

- Gain hands-on experience with foundational classification techniques in R
- Understand when to apply each method based on data characteristics
- Learn how to assess classification model performance using appropriate metrics
